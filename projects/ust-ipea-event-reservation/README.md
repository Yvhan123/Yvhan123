# UST IPEA Event Reservation System

## 📋 Project Overview

A comprehensive event reservation and management system designed for the University of Santo Tomas Institute of Physical Education and Athletics (UST IPEA).

## 🎯 Project Goals

- Streamline event booking and reservation processes
- Provide efficient event management tools
- Enhance user experience for event organizers and attendees
- Implement secure authentication and authorization

## ✨ Key Features

### Event Management
- Create and manage events
- Event scheduling with calendar integration
- Event details and descriptions
- Capacity management

### Reservation System
- User-friendly booking interface
- Real-time availability checking
- Reservation confirmation and notifications
- Booking history tracking

### User Management
- User registration and authentication
- Role-based access control (Admin, Organizer, User)
- User profile management

### Administrative Dashboard
- Event analytics and reporting
- User management interface
- System configuration
